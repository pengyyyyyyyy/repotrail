# 前端设计

界面根据提供的 Cursor 设计分析组织，采用暖米色画布、暖黑文字、浅色源码面板和少量橙色主操作。显示标题使用 400 字重，代码采用 JetBrains Mono 字体栈，界面采用 Inter 字体栈与系统回退。

## 工作区

导航、阅读路线与源码组成三栏结构。源码占据主要宽度，步骤选择与高亮代码同步。页面保留仓库信息、操作反馈和导出入口。

小屏将步骤与源码按阅读顺序堆叠，文件导航收起，阅读起点改为横向选择。

## API 接入

右上角模型按钮与侧栏均可打开配置窗口。配置包含连接名称、服务地址、密钥和模型 ID。支持服务商模板、获取模型列表、手动填写模型、连接测试与即时保存。

交互流程参考 OpenMinis 的服务商配置页面与模型获取接口。配置窗口采用分栏布局，左侧选择模板，右侧完成表单。

## 视觉与细节

间距遵循 4px 网格。面板使用细边框建立层次，按钮与输入框采用 8px 圆角。动作反馈使用短时颜色变化，并支持 reduced-motion。空输入、连接错误、保存反馈与键盘焦点使用明确状态。
